# Plumbfix

Modern, high-conversion website for a New Zealand plumbing business.

## Getting started

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Notes

- The callback form POSTs to `/api/request-callback` and redirects back to the home page.
- The API currently logs submissions server-side (placeholder for email/CRM integration).
